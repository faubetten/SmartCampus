Código:
DockerFile -> ficheiro principal
.dockeringore -> ignorar files como node_modules

Tudo comeca com FROM -> seleciona imagem a usar 
ex: FROM node:22 -> imagem node versao 22

fazer download de dependencias primeiro

WORKKDIR /app -> define onde o docker comeca

COPY package*.json ./ -> copia package files

RUN npm install -> instala dependencias

COPY .. -> copia tudo

ENV PORT=9000 -> variavel ambiente

EXPOSE 9000 -> caso variavel seja port para docker usar

CMD ["npm", "start"] -> Correr app 

Terminal:

docker build -t *nome* . -> criar imagem com tag nome e path

docker run -p 9000:9000 *nome* -> correr container com port forwarding caso necessario

GUI:

docker scout -> analisa packages por falhas de seguranca

Docker Compose -> para multicontainers

compose.yaml: -> file para criar multicontainers

services:
	backend:
		build: . -> usa DockerFile criado
		ports: -> port forwarding necessario
			- '9000:9000'
	db:
		image: postgres:latest -> usa imagem base de postgres
		environment: -> variaveis necessarias
			POSTGRES_USER: user
			POSTGRES_PASSWORD: pass
			POSTGRES_DB: mydb
		volumes: -> volume onde data vai parar caso container seja apagado
			-postgres_data:/var/lib/postgressql/data
volumes: -> cria ficheiro de volumes
	postgres_data:
